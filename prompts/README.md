# prompts/

Few-shot lesson prompts for the SDD Trainer (AIA_07 pattern).

## Purpose

Each of the 6 SDD domains gets a lesson skeleton here: structure, key theses,
and canonical examples of **SHALL** requirements with **WHEN/THEN** scenarios.
GigaChat unfolds a skeleton into a full lesson adapted to the student's level
(hybrid authorship, grilling Q10); quizzes with reference answers live in
`data/`.

## Planned files (phase 1, `add-console-trainer`)

- `sdd-fundamentals.md` — spec as the source of truth, plan before code
- `openspec-structure.md` — specs/ vs changes/
- `requirement-writing.md` — SHALL requirements + WHEN/THEN scenarios
- `change-proposals.md` — proposal -> design -> tasks
- `openspec-workflow.md` — explore -> propose -> apply -> archive
- `brownfield-sdd.md` — incremental changes in a live project
