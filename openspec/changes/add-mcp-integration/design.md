# Design: Add MCP Integration (Phase 2)

## ADR-010: MCP через официальный Python SDK (FastMCP, stdio)

**Контекст.** Преподаватель (консультация №1): главное — работающий прототип, код вторичен. Пакет `mcp==1.27.1` уже запинен в requirements.txt (скелет Фазы 0; ADR-001 упоминал MCP-транспорт). Python 3.12, FastMCP импортируется (`from mcp.server.fastmcp import FastMCP`).

**Решение.** MCP-сервер строится на FastMCP из официального SDK, транспорт stdio (стандарт локальных MCP-серверов). Декораторный стиль FastMCP даёт минимальный код обёрток; ядро (граф, tools, память) не переписывается.

**Альтернативы.** (a) Свой JSON-RPC поверх stdio — больше кода, против «код вторичен». (b) HTTP/SSE-транспорт — нужен сервер-процесс и порт; stdio проще для локального демо. Отклонены.

## Ключевое решение: пошаговое возобновление графа

Инструменты сессии НЕ гоняют граф целиком: каждый вызов возобновляет чекпоинченный граф (ADR-008, thread_id = student) с последним ответом ученика и собирает события до следующего interrupt; клиенту возвращается payload interrupt (калибровочный вопрос / уточняющий вопрос / вопрос квиза) или финальный результат (вердикт оценки, урок, вердикт квиза, сводка). Состояние живёт в существующем SqliteSaver — Фаза 1 переиспользуется целиком, интерактивное демо и рестарт-устойчивость получаются бесплатно.

## Набор инструментов (тонкие обёртки)

- Сессия (пошагово): `start_session(student, repo_path?)` → калибровочный вопрос; `answer_calibration(answer)` → вердикт + маршрут (или clarification-вопрос); `answer_clarification(answer)` → вердикт; `answer_quiz_question(answer)` → следующий вопрос или F1-вердикт квиза.
- Прямые: `analyze_repo(path)` → RepoAnalysis; `search_docs(query)` → Tavily-результаты; `get_progress(student)` → training-state (domain, score, streak, completed lessons).

Точный состав сессийных инструментов уточняется реализацией по факту interrupt-точек графа Фазы 1; принцип неизменен: один вызов = один шаг до следующего interrupt.

## Демо-способность

- Демо-клиент на SDK (in-process, stdio) прогоняет полный сеанс — автодемо для скринкаста
- Конфиг-пример для реальных MCP-хостов (Claude Desktop / OpenClaw) в docs/
- Смоук-чеклист MCP по образцу docs/smoke-checklist.md
